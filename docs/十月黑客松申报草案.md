## 项目与使用场景

Fusekite 是 MoonBit 原生布尔推理与小型组合逻辑规划库。学生或实验者输入单输出真值表，取得精确 SOP（与或式），核对等价或定位反例，再估算直接门级结构与 SN74HC 封装数量。化简限 1–8 输入；逻辑验证和数量估算不包含引脚、时序、负载或实物验证。

## 已实现基线与九月反馈

以九月末提交 [`3371536`](https://github.com/Lyhdsba/Fusekite/tree/3371536742257f3834f71120b9009dd3ef820539)为基线：已有 ROBDD、独立 CNF/Tseitin/DPLL SAT、1–8 位受限 QF_BV、精确 SOP、BDD/SAT 等价核验、门数/封装估算、三个电路示例和自动检查入口。历史验证见[开发记录](../DEVELOPMENT.md)，不计作十月新增工作。

九月未通过原因按留存草案记录为：ROBDD 与 MoonBDD 重叠，扩展关系不清，提交前须核对原始通知。两者确有 ROBDD/布尔分析重合；Fusekite 保持独立实现，侧重 SAT/QF_BV 与小真值表到器件估算的链路。当前没有依赖、复用或集成 MoonBDD；能力互补不代表已为 MoonBDD 扩展功能。继续独立实现的理由是保留这一可单独验证的应用链路，后续复用仍须评估。详见已有[范围对比](MoonBDD与Fusekite范围对比.md)；十月的关系澄清文档不作为主要功能增量。

**计划中，尚未实现。** 在现有 1–8 输入及无关项规格内，对补函数做精确覆盖并转换为 POS；明确常量、无关项语义和确定性选择规则。新增 POS 表达/求值 API、BDD/SAT 等价核验、SOP/POS 对照示例，以及边界和错误候选回归。用途是帮助学习者比较同一函数的两种两级表达；不承诺任意门网络或封装数全局最优，也不扩展为完整 SMT/EDA。
